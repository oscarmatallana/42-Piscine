# 📘 Project Overview

This repository contains a collection of exercises and projects completed during my Piscine at 42 Berlin 🚀

The focus of these projects is not only to learn the C language, but also to develop a strong understanding of:
- low-level programming
- algorithms and logic
- memory management
- shell environments
- problem-solving under constraints
- clean and structured coding practices

Many exercises intentionally restrict the use of standard libraries and functions, encouraging a deeper understanding of what happens “under the hood” 🔧

---

# 🧩 C02 — String Manipulation & Validation

Working with strings in C means working close to memory — carefully and precisely.

This module focuses on:
- recreating standard string functions such as `strcpy()` and `strncpy()`
- validating character types (alphabetic, numeric, uppercase, lowercase, printable)
- transforming strings (uppercase, lowercase, capitalization)

In short: teaching strings some manners 😄

---

# 🔍 C03 — String Comparison & Search

This module continues the exploration of C strings by rebuilding functions such as:
- `strcmp()`
- `strncmp()`
- `strcat()`
- `strncat()`
- `strstr()`

A hands-on dive into comparisons, concatenation, and substring searching without relying on the standard library.

---

# 🔢 C04 — Basic I/O & Number Handling

Here the focus shifts toward:
- displaying characters, strings, and numbers
- converting strings into integers (`atoi`)
- handling signs, whitespace, and parsing logic manually

A great exercise in understanding how computers interpret text as numbers 🧠

---

# 🖥️ C06 — Command-Line Arguments

This module introduces command-line arguments (`argc` / `argv`) and explores how programs interact with terminal input.

Projects include:
- printing program names
- displaying arguments in normal and reverse order
- sorting arguments in ASCII order

Simple concepts — surprisingly useful everywhere.

---

# ⚙️ CPC00 — The Very First Steps in C

The foundations.

These exercises focus on:
- printing characters and numbers using only `write()`
- displaying alphabets and number combinations
- understanding loops and conditions
- thinking algorithmically from the beginning

Sometimes the smallest exercises teach the biggest lessons.

---

# 🧠 CPC01 — Pointers & Memory Basics

Welcome to pointers — one of the most powerful (and intimidating 😅) concepts in C.

Topics include:
- manipulating values through memory addresses
- swapping variables
- division and modulo operations via pointers
- multi-level pointers
- working directly with memory references

This module is where C starts feeling *really* low-level.

---

# 🐚 CPShell00 — Linux & Shell Fundamentals

An introduction to working in Unix/Linux environments through shell exercises.

Topics include:
- file permissions
- symbolic links
- SSH keys
- tar archives
- shell scripting
- Git command automation

Because software engineering also means understanding the environment where software runs.

---

# 🧪 ExamPractice

A collection of small practice exercises focused on:
- logic
- loops
- terminal output
- argument handling
- coding under time pressure

Including classics like:
- `FizzBuzz`
- argument parsing
- quick algorithmic drills

---

# 🏗️ Rush00 — Drawing with Code

A fun introduction to procedural generation in C.

The goal:
- generate rectangles of different sizes directly in the terminal
- handle borders, corners, and dimensions dynamically

Simple on paper. Surprisingly satisfying in practice.

---

# 🏙️ Rush01 — Skyscrapers Puzzle Solver

A logic puzzle solver written in C.

The challenge:
- place skyscrapers of different heights in a 4×4 grid
- ensure visibility constraints are respected from every direction
- avoid duplicate heights in rows and columns

This project explores:
- constraint solving
- backtracking
- algorithmic reasoning
- structured problem decomposition

The kind of puzzle that starts innocent… and quickly becomes addictive 😄
